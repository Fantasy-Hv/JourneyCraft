# 收藏模块 API 接口文档

---

## 通用说明

### 响应格式

所有接口响应统一返回Response包裹的反参VO对象

### 错误码见common包枚举

### 认证方式

需要在请求头中携带 JWT Token:

```
Authorization: Bearer <token>
```

---

## 1. 收藏管理

### 1.1 添加收藏

**接口**: `POST /api/favorite`

**请求头**: 需要携带 Token

**请求 VO**: `FavoriteAddReqVO`

| 参数名          | 类型      | 必填  | 说明                                   |
| ------------ | ------- | --- | ------------------------------------ |
| favoriteType | Integer | 是   | 收藏类型 (0:景点 1:校园 2:建筑 3:设施 4:日记 5:路线) |
| favoriteId   | Long    | 是   | 收藏对象 ID                              |
| collectionId | Long    | 否   | 收藏夹 ID (不传则添加到默认收藏夹)                 |

**请求示例**:

```json
{
  "favoriteType": 0,
  "favoriteId": 1001,
  "collectionId": 1,
}
```

**响应 VO**: `FavoriteItemRspVO`

| 字段             | 类型      | 说明                             |
| -------------- | ------- | ------------------------------ |
| id             | Long    | 收藏记录 ID                        |
| userId         | Long    | 用户 ID                          |
| favoriteType   | Integer | 收藏类型                           |
| favoriteId     | Long    | 收藏对象 ID                        |
| collectionId   | Long    | 收藏夹 ID                         |
| collectionName | String  | 收藏夹名称                          |
| createdAt      | String  | 创建时间 (格式: yyyy-MM-dd HH:mm:ss) |

**

**响应示例**:

```json
{
  "code": 200,
  "message": "success",
  "data": null
}
```

### 1.3 获取收藏列表

**接口**: `GET /api/favorite/list`

**请求头**: 需要携带 Token

**请求 VO**: `FavoriteListReqVO`

| 参数名          | 类型      | 必填  | 说明                                               |
| ------------ | ------- | --- | ------------------------------------------------ |
| favoriteType | Integer | 否   | 收藏类型过滤 (0:景点 1:校园 2:建筑 3:设施 4:日记 5:路线，不传则查询全部类型) |

| size         | Integer | 否   | 每页数量 (默认 10, 最大 100)                             |

```
GET /api/favorite/list?favoriteType=0&collectionId=1&page=1&size=10
```

### 检查是否已收藏

**接口**: `GET /api/favorite/check`

**请求头**: 需要携带 Token

**请求 VO**: `FavoriteCheckReqVO`

| 参数名          | 类型      | 必填  | 说明      |
| ------------ | ------- | --- | ------- |
| favoriteType | Integer | 是   | 收藏类型    |
| favoriteId   | Long    | 是   | 收藏对象 ID |

**请求示例**:

```
GET /api/favorite/check?favoriteType=0&favoriteId=1001
```

**响应 VO**: `FavoriteCheckRspVO`

| 字段           | 类型      | 说明                   |
| ------------ | ------- | -------------------- |
| isFavorited  | Boolean | 是否已收藏                |
| favoriteId   | Long    | 收藏记录 ID (未收藏时为 null) |
| collectionId | Long    | 收藏夹 ID (未收藏时为 null)  |

**响应示例** (已收藏):

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "isFavorited": true,
    "favoriteId": 1,
    "collectionId": 1
  }
}
```

**响应示例** (未收藏):

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "isFavorited": false,
    "favoriteId": null,
    "collectionId": null
  }
}
```

## 2. 收藏夹管理

### 2.1 创建收藏夹

**接口**: `POST /api/favorite/collection`

**请求头**: 需要携带 Token

**响应示例**:

```json
{
  "code": 200,

    "userId": 1001,
    "collectionName": "北京旅行",
    "itemCount": 0,
```

### 2.4 删除收藏夹

**接口**: `DELETE /api/favorite/collection/{id}`

**请求头**: 需要携带 Token

**路径参数**:
| 参数名 | 类型 | 说明 |
|--------|------|------|
| id | Long | 收藏夹 ID |

**说明**: 

- ❌ 不能删除默认收藏夹
- ✅ 删除收藏夹时，该收藏夹下的所有收藏记录将一并删除

**响应**: 无特殊返回数据

**响应示例**:

```json
{
  "code": 200,
  "message": "success",
  "data": null
}
```

**错误示例** (尝试删除默认收藏夹):

```json
{
  "code": 400,
  "message": "不能删除默认收藏夹",
  "data": null
}
```

## 附录

### A. 枚举值定义

#### 收藏类型 (favoriteType)

```
0: 景点
1: 校园
2: 建筑
3: 设施
4: 日记
5: 路线
```

### B. 业务规则说明

1. **默认收藏夹**
   
   - 添加收藏时如果不指定 `collectionId`，自动添加到默认收藏夹
   - 默认收藏夹在用户第一次默认收藏操作（不指定收藏夹）时创建并且并且不可被删除

2. **重复收藏处理**
   
   - 同一用户对同一对象只能收藏一次
   - 如果尝试重复收藏，返回错误提示："该对象已在收藏夹中"

3. **收藏夹数量限制**
   
   - 每个用户最多创建 20 个自定义收藏夹 (不包括默认收藏夹)

4. **收藏数量限制**
   
   - 每个收藏夹最多容纳 500 个收藏项
   - 单个用户总收藏数不超过 2000 个
