## favorite (收藏关系表)

| 字段            | 类型       | 长度  | 说明      | 枚举值/示例                            |
| ------------- | -------- | --- | ------- | --------------------------------- |
| id            | BIGINT   | 20  | 主键      | 1                                 |
| user_id       | BIGINT   | 20  | 用户 ID   | 1001                              |
| favorite_type | TINYINT  | 1   | 收藏类型    | **0:景点 1:校园 2:建筑 3:设施 4:日记 5:路线** |
| favorite_id   | BIGINT   | 20  | 收藏对象 ID | 1                                 |
| collection_id | BIGINT   | 20  | 所属收藏夹   | 1                                 |
| created_at    | DATETIME | -   | 创建时间    | -                                 |

## collections(用户-收藏夹关联表)

id：收藏夹id,BIGINT(20),

user_id:创建该收藏夹的用户id，BIGINT //每个用户都有一个默认收藏夹

collection_name:收藏夹名称，VARCHAR（20）

created_at:创建时间，DATETIME

需要建立user_id和coolection_name的联合唯一索引
