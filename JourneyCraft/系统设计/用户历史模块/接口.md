## 10. 历史模块 (history)

**所属模块**: history  
**依赖模块**: user

### 10.1 获取浏览历史

**接口**: `GET /api/history/view`

**请求头**: 需要携带 Token

**请求参数**:
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| type | Integer | 否 | 目标类型 |
| page | Integer | 否 | 页码 |
| size | Integer | 否 | 每页数量 |

**响应参数**:
| 字段 | 类型 | 说明 |
|------|------|------|
| list | Array | 历史记录列表 |
| total | Integer | 总数 |

**历史记录对象**:
| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 记录 ID |
| targetType | Integer | 目标类型 |
| targetId | Long | 目标 ID |
| targetName | String | 目标名称 |
| targetImage | String | 目标图片 |
| viewDuration | Integer | 浏览时长 (秒) |
| viewTime | String | 浏览时间 |

---

### 10.2 获取搜索历史

**接口**: `GET /api/history/search`

**请求头**: 需要携带 Token

**请求参数**:
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| type | Integer | 否 | 搜索类型 |
| limit | Integer | 否 | 返回数量 |

---

### 10.3 获取导航历史

**接口**: `GET /api/history/navigation`

**请求头**: 需要携带 Token

**请求参数**:
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| scenicAreaId | Long | 否 | 景区 ID |
| page | Integer | 否 | 页码 |
| size | Integer | 否 | 每页数量 |

---

### 10.4 记录浏览

**接口**: `POST /api/history/view`

**请求头**: 需要携带 Token

**请求参数**:
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| targetType | Integer | 是 | 目标类型 |
| targetId | Long | 是 | 目标 ID |
| viewDuration | Integer | 否 | 浏览时长 (秒) |

---

### 10.5 清空历史

**接口**: `DELETE /api/history/clear`

**请求头**: 需要携带 Token

**请求参数**:
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| type | String | 否 | 历史类型 (view/search/navigation)，不传则清空全部 |

---
