7. 日记模块 (diary)

**所属模块**: diary  
**依赖模块**: user, scenic, file

### 7.1 创建日记

**接口**: `POST /api/diary`

**请求头**: 需要携带 Token

**请求参数**:
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| title | String | 是 | 标题 |
| content | String | 是 | 内容 (Markdown) |
| scenicAreaId | Long | 否 | 关联景区 ID |
| tripId | Long | 否 | 关联行程 ID |
| coverImage | String | 否 | 封面图 URL |
| images | Array | 否 | 图片 URL 列表 |
| videos | Array | 否 | 视频 URL 列表 |
| path | Array | 否 | 游览路径 |
| tags | Array | 否 | 标签 |
| rating | Double | 否 | 评分 |
| mood | String | 否 | 心情 |
| weather | String | 否 | 天气 |
| companions | Array | 否 | 同行人 |
| status | Integer | 否 | 可见性 (0:私密 1:公开) |

**请求示例**:
```json
{
  "title": "黄山三日游 - 云海奇观",
  "content": "# 黄山之旅\n\n第一天到达了黄山脚下...\n\n## 景点推荐\n- 迎客松\n- 光明顶\n- 西海大峡谷",
  "scenicAreaId": [1001,1002],
  "tripId": 2001,
  "coverImage": "http://localhost:9000/journeycraft/diary/cover_001.jpg",
  "images": [
    "http://localhost:9000/journeycraft/diary/img_001.jpg",
    "http://localhost:9000/journeycraft/diary/img_002.jpg",
    "http://localhost:9000/journeycraft/diary/img_003.jpg"
  ],
  "videos": [
    "http://localhost:9000/journeycraft/diary/video_001.mp4"
  ],
  "path": [
    {"lat": 30.135, "lng": 118.163, "name": "云谷寺"},
    {"lat": 30.142, "lng": 118.171, "name": "白鹅岭"},
    {"lat": 30.138, "lng": 118.168, "name": "始信峰"}
  ],
  "tags": ["自然风光", "登山", "云海", "日出"],
  "rating": 4.8,
  "mood": "兴奋",
  "weather": "晴朗",
  "companions": ["张三", "李四"],
  "status": 1
}
```

**响应参数**:
| 字段 | 类型 | 说明 |
|------|------|------|
| diaryId | String | 日记 ID (MongoDB ObjectId) |

**响应示例**:
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "diaryId": "65f8a1b2c3d4e5f6a7b8c9d0"
  }
}
```

### 7.4 更新日记

**接口**: `PUT /api/diary/{id}`

**请求头**: 需要携带 Token (仅作者可修改)

**请求参数**: 同创建日记

**请求示例**:
```json
{
  "title": "黄山三日游 - 云海奇观（修订版）",
  "content": "# 黄山之旅\n\n第一天到达了黄山脚下...\n\n## 更新内容\n补充了一些实用建议",
  "scenicAreaId": 1001,
  "coverImage": "http://localhost:9000/journeycraft/diary/cover_001_new.jpg",
  "images": [
    "http://localhost:9000/journeycraft/diary/img_001.jpg",
    "http://localhost:9000/journeycraft/diary/img_004.jpg"
  ],
  "tags": ["自然风光", "登山", "云海", "日出", "攻略"],
  "rating": 4.9,
  "status": 1
}
```

**响应示例**:
```json
{
  "code": 200,
  "message": "更新成功",
  "data": null
}
```

### 7.7 添加评论

**接口**: `POST /api/diary/{id}/comment`

**路径参数**:
| 参数名 | 类型 | 说明 |
|--------|------|------|
| id | String | 日记 ID |

**请求参数**:
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| content | String | 是 | 评论内容 |
| parentId | String | 否 | 父评论 ID (回复时填写) |
| images | Array | 否 | 评论图片 |

**请求示例** (新增评论):
```json
{
  "content": "写得真好！黄山的云海确实很壮观，请问最佳观赏时间是几点？",
  "images": [
    "http://localhost:9000/journeycraft/comment/img_001.jpg"
  ]
}
```

**请求示例** (回复评论):
```json
{
  "content": "一般是早上5-6点，建议在光明顶观看",
  "parentId": "65f8a1b2c3d4e5f6a7b8c9e1"
}
```

**响应示例**:
```json
{
  "code": 200,
  "message": "评论成功",
  "data": {
    "commentId": "65f8a1b2c3d4e5f6a7b8c9e2"
  }
}
```

### 7.9 删除评论

**接口**: `DELETE /api/diary/{diaryId}/comment/{commentId}`

**请求头**: 需要携带 Token (仅评论发布者或日记发布者可删除)

**路径参数**:
| 参数名 | 类型 | 说明 |
|--------|------|------|
| commentId | String | 评论 ID |

**权限说明**:
- 评论发布者可以删除自己的评论
- 日记发布者可以删除该日记下的任意评论
- 其他用户无权删除，实现时要注意关联查找

**请求示例(需要携带token)**:
```
DELETE /api/diary/comment/65f8a1b2c3d4e5f6a7b8c9e1

```

**响应示例** (成功):
```json
{
  "code": 200,
  "message": "删除成功",
  "data": null
}
```

**响应示例** (无权限):
```json
{
  "code": 403,
  "message": "没有权限",
  "data": null
}
```

**响应示例** (评论不存在):
```json
{
  "code": 404,
  "message": "评论不存在",
  "data": null
}
```
