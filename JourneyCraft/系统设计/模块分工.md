## 二、详细任务分配

### 2.1 王哲（基础层 + 核心数据层）

**负责模块**: `user`、`auth`、`oss`、`scenic`

**工作量评估**:

| 模块 | 复杂度 | 主要内容 |
|------|--------|---------|
| user | 中 | 用户 CRUD、偏好设置 |
| auth | 低 | JWT 认证、拦截器 |
| oss | 低 | MinIO 集成、文件上传 |
| scenic | 高 | 景点/校园/建筑/设施 CRUD、搜索 |

**核心职责**:
- 搭建用户体系和认证框架
- 搭建对象存储服务
- 维护核心景点数据

**依赖关系**: 无外部依赖，可并行开发

**开发顺序**: `user` / `oss` → `auth` → `scenic`

---

### 2.2 刘方正（导航算法 + 协同规划）

**负责模块**: `navigation`、`group`、`expense`

**工作量评估**:

| 模块 | 复杂度 | 主要内容 |
|------|--------|---------|
| navigation | 高 | 路径规划算法（Dijkstra/A*）、TSP、室内导航、拥挤度计算 |
| group | 中 | 小组管理、偏好收集、方案综合 |
| expense | 中 | 账单 CRUD、统计分析 |

**核心职责**:
- 实现核心路径规划算法
- 多人协同方案生成
- 账单管理

**依赖关系**:
- 依赖王哲的 `scenic` 模块
- `group` 需要调用 `navigation` 和 `recommend`

**开发顺序**: `navigation` → `group` → `expense`

---

### 2.3 黄严（推荐算法 + 内容生态）

**负责模块**: `recommend`、`diary`、`favorite`、`history`

**工作量评估**:

| 模块 | 复杂度 | 主要内容 |
|------|--------|---------|
| recommend | 高 | 协同过滤、热度计算、排序算法 |
| diary | 高 | 日记 CRUD、MongoDB、媒体管理、互动功能 |
| favorite | 低 | 多态收藏管理 |
| history | 低 | 浏览/搜索/导航历史记录 |

**核心职责**:
- 推荐算法实现
- 日记内容生态
- 用户行为记录与收藏

**依赖关系**:
- 依赖王哲的 `user`、`scenic`、`oss` 模块
- `diary` 依赖 `oss`

**开发顺序**: `favorite` / `history` → `diary` → `recommend`

## 三、开发阶段规划

### 阶段一：基础框架（Week 1-2）

| 人员 | 任务 |
|------|------|
| 王哲 | user, auth, oss, scenic 基础 CRUD |
| 刘方正 | navigation 路网数据结构、基础路径算法 |
| 黄严 | favorite, history 基础 CRUD，diary 基础框架 |

### 阶段二：核心功能（Week 3-4）

| 人员 | 任务 |
|------|------|
| 王哲 | scenic 搜索、拥挤度上报 |
| 刘方正 | navigation 完整算法、group 协同规划、expense |
| 黄严 | diary 完整功能、recommend 推荐算法 |

### 阶段三：联调测试（Week 5）

| 人员 | 任务 |
|------|------|
| 王哲 + 刘方正 | scenic ↔ navigation 接口联调 |
| 刘方正 + 黄严 | group ↔ recommend 接口联调 |
| 全员 | 端到端测试、性能优化 |

## 五、跨人员接口约定

### 5.1 王哲 → 刘方正

| 接口 | 说明 |
|------|------|
| `GET /api/scenic/{id}/buildings` | 获取建筑物列表 |
| `GET /api/scenic/{id}/facilities` | 获取设施列表 |

### 5.2 王哲 → 黄严

| 接口 | 说明 |
|------|------|
| `GET /api/scenic/list` | 获取景点列表（用于推荐） |
| `POST /api/file/upload/image` | 上传图片（用于日记） |

### 5.3 刘方正 → 黄严

| 接口 | 说明 |
|------|------|
| `POST /api/navigation/route` | 路径规划（用于 group 方案生成） |
| `POST /api/navigation/multi-route` | 多目标路线规划 |

### 5.4 黄严 → 刘方正

| 接口 | 说明 |
|------|------|
| `GET /api/recommend/scenic` | 热门景点推荐 |
| `GET /api/recommend/personalized` | 个性化推荐 |
